THE TANA HOUSE — DISH PHOTO PROMPTS
===================================
How to use
----------
1. Paste a prompt into an image generator (ChatGPT, Gemini, Midjourney, etc.).
2. Save the result as a .jpg with the exact file name shown.
3. Put it in:  assets/img/dishes/
   All 62 menu items now have local illustrations. Replacing a file updates its thumbnail in both languages.

Big section photos (the arch photos) work the same way: save as assets/img/photos/<name>.jpg
   pancakes, waffles, omelets, huevos, benedict, plates, burgers, sandwiches, soups, drinks, desserts, hero
   Only existing local section photos are used; there are no external stock-photo fallbacks.

New menu thumbnails (November 2026)
   58 new illustrations were created with the built-in image_gen tool, completing all 62 items.
   Exact generation prompts: assets/img/dishes/generation-prompts.json.
   New files are optimized to 320 x 320 JPEG and displayed at 80px / 64px on desktop / mobile.

Tip: AI pictures are only approximate. Customers notice when a plate looks different in person,
so the best long-term option is photographing your real plates near a window, then using the same file names.
